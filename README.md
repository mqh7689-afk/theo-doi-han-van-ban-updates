# Kho cập nhật thử nghiệm V3.0

Chỉ chứa mã phía trình duyệt của ứng dụng, không chứa dữ liệu người sử dụng.

- `release.json`: phiên bản hiện được phát hành.
- `versions/3.0.1/app.js`: mã giao diện đúng SHA-256 trong release.json.
- `index.html`: trang giới thiệu tối giản.

**Chưa sử dụng cho văn bản mật hoặc dữ liệu thực.** Chỉ bật cập nhật sau khi xác minh nguồn và quyền quản trị kho, kiểm thử trình duyệt và tương thích.
